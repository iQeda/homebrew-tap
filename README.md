# homebrew-tap

Homebrew Cask tap for iQeda apps.

## Usage

```bash
brew tap iQeda/tap
brew install --cask mydashboard
```

## Available Casks

| Cask | Description |
|------|-------------|
| `mydashboard` | Mac app/site launcher dashboard |
| `memorize` | Anki-compatible spaced repetition app, vocab-focused (Apple Silicon only) |
